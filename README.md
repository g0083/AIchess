# 将棋盤チェス — PWA Chess

ブラウザだけで快適に動く、本格対局チェス PWA アプリです。  
端末にインストールすれば、**AI対戦・オフライン対面対局・学習モードのすべてが通信なしで動作**します。

GitHub Pages: https://g0083.github.io/AIchess/

---

## 主な機能

### 1. 多彩な対戦モード

| モード | 特徴 |
|---|---|
| **AI対戦** | 初心者から上級者まで対応する8段階の難易度。性格6種（堅実／攻撃的／保守的／大胆／長線／交換的）やリアルタイム悪手診断・脅威検知・AIコーチ解説を搭載。 |
| **オフライン2人対局** | 1台の端末を挟んで対面対局。対局時計・盤面自動反転・投了・引き分け提案に対応。 |
| **P2Pオンライン対戦** | 専用サーバーを介さず端末間で直接WebRTC接続。QRコードを読み取るだけで手軽に対局可能（チャット機能付き）。 |
| **棋譜検討・盤面分析** | 盤面局面の自由配置、FEN / PGN の入出力、Stockfishによるリアルタイム評価値グラフおよび候補手の可視化。 |

### 2. 人間らしい思考を再現する AI エンジン

Stockfish 19 (WebAssembly) を採用。単に探索深さを制限するだけでなく、以下の要素を組み合わせて自然な対局感を実現しています。

- **探索制御**：`depth` / `movetime` / `nodes` の細やかな調整
- **MultiPV による候補手分散**：最善手との評価差に応じた手選択
- **性格（Personality）**：駒交換を好む、攻勢を重視するなど6系統のプレイスタイル
- **初心者のミス再現**：無意味に駒を捨てるのではなく、「両取りやピンの脅威を見落とす」といった実戦的な失点を模した調整

通常時は軽量版エンジン（約1.8MB、単一スレッド・完全オフライン動作）が起動します。設定からフル版エンジン（約99MB）への切り替えも可能です。

### 3. 初心者から学べる学習モード

- **段階的レッスン**：駒の動きや基本ルールから実戦手筋までを網羅
- **戦術パズル（20問）**：フォーク、ピン、スキューア、バックランクメイト、スマザードメイト、アンパッサン、オポジションなど。全問を Stockfish 19 で厳密に検証済み
- **定石集（オープニング）**：ルイ・ロペス、シシリアン・ディフェンス、フレンチ・ディフェンスなど代表的な序盤定石の手順と方針を盤上で確認
- **用語集**：チェスの専門用語を日本語で体系的に整理

### 4. リアルタイム AI コーチ機能

対局中、AIが盤面の状況を即座に判定し、初心者にもわかりやすい日本語で助言します。
相手の危険な脅威（メイトの危機や浮いている駒への攻撃）を警告し、好手の狙いや理由を丁寧に解説します。

### 5. あらゆる画面に最適化されたレスポンシブ設計

`ResizeObserver` と `dvh`（Dynamic Viewport Height）を活用し、画面幅やブラウザツールバーの開閉に左右されない安定した盤面描画を実現しています。

- **PC・大型ディスプレイ（1280px〜）**：プレイヤー情報・盤面・サイドパネルの3カラム表示
- **タブレット（768px〜1279px）**：盤面とサイドパネルの2カラム構成
- **スマートフォン（〜767px）**：1カラム表示。情報パネルはスムーズなボトムシートで展開
- **横画面（スマホ Landscape）**：高さを有効活用する省スペース2カラム構成

テーマは和紙の温かみを感じる3種類（和紙・セピア・墨）から選択できます。

## 技術構成

- **フロントエンド**: React 19 / TypeScript / Vite 8
- **チェスロジック**: `chess.js` (ルール判定・FEN/PGN解析)
- **盤面UI**: `@lichess-org/chessground`
- **チェスエンジン**: Stockfish 19 (WebAssembly)
- **P2P通信**: `trystero` (WebRTC + Nostr / BitTorrent リレー)
- **PWA**: `vite-plugin-pwa` (Workbox によるオフラインキャッシュ制御)
- **駒グラフィック**: 本プロジェクト独自の高品質ベクターSVG（Unicode文字や絵文字不使用）

## 開発とセットアップ

### 前提条件
- Node.js 20 以上
- npm

### コマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動（エンジンを public/ へコピーして起動）
npm run dev

# 型チェックと本番ビルド
npm run build

# 本番ビルド成果物のローカルプレビュー
npm run preview

# 全体検証（コンテンツ整合性・パズル正当性・ユニットテスト）
npm run verify
```

### 品質検証スクリプト

プロジェクトの信頼性を担保するため、3層の自動検証を導入しています。

```bash
npm run verify:content   # テキスト整合性、FEN構文、手番の合法性を検査
npm run verify:puzzles   # 全パズルの解答手が Stockfish 19 の最善手と一致するか検査
npm test                 # 全89件のユニットテストを実行 (Vitest)
```

## デプロイ（GitHub Pages）

リポジトリの `master` ブランチに push すると、GitHub Actions ワークフロー（`.github/workflows/deploy.yml`）が自動で検証とビルドを行い、GitHub Pages にデプロイします。

### 初回設定
1. GitHub リポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** で **GitHub Actions** を選択して保存

本番環境のサブパス（`/AIchess/`）への配備にも完全対応しており、相対パスベースでビルドされるためルート配信・サブパス配信のどちらでも正常に動作します。
